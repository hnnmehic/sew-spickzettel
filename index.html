Panache Repository – Spickzettel

Repository-Pattern (kein Active Record): @ApplicationScoped class XRepository implements PanacheRepository<X>. Panache erlaubt Kurz-Queries ohne select/from: "field", "field = ?1", "a = :a and b > :b".

Typische Repository-Methoden
@ApplicationScoped
public class FruitRepository implements PanacheRepository<Fruit> {

    public List<Fruit> findAllOrderedByName() {
        return listAll(Sort.by("name"));                        // Sort.by("a").and("b", Sort.Direction.Descending)
    }

    public List<Fruit> findByClimacteric(boolean climacteric) {
        return list("climacteric", Sort.by("name"), climacteric); // Kurzform: "climacteric = ?1"
    }

    public Optional<Fruit> findByName(String name) {
        return find("name", name).firstResultOptional();
    }

    public List<Fruit> findWarmerThan(double min) {
        return list("minTemperature >= ?1 order by name", min);
    }

    public List<Fruit> search(String text) {
        return list("lower(name) like :q", Parameters.with("q", "%" + text.toLowerCase() + "%"));
    }

    public long countByClimacteric(boolean c) {
        return count("climacteric", c);
    }

    public List<Container> findByVoyage(long voyageId) {         // Pfad über Beziehung: voyage.id
        return getEntityManager().createQuery(
                "select c from Container c where c.voyage.id = :id order by c.containerNumber", Container.class)
                .setParameter("id", voyageId).getResultList();
    }
}

Aufgabe 1 – TypedQuery (Summe einer Reise)

TypedQuery<T> = em.createQuery(jpql, T.class). Ergebnis-Typ muss passen:

  • sum(double-Feld) → Double, sum(int/long-Feld) → Long
  • count(...) → Long, avg(...) → Double, max/min → Feldtyp
  • sum ohne Zeilen = null → deshalb coalesce(sum(x), 0.0) (bzw. 0 bei Long)

Navigation über Beziehungen mit Punkt: ci.container.voyage.id (impliziter Join).

Lösung CargoItemRepository.totalWeightByVoyage

}

Aufgabe 2 – @NamedQuery + Konstruktor-Ausdruck (DTO-Projektion)

  • @NamedQuery kommt auf die Entity (unter @Entity/@Table).
  • Konstruktor-Ausdruck braucht den voll qualifizierten Klassennamen: select new at.htl....dto.FruitWeightDto(...).

Aufgabe 3 – left join + group by + having

  • left join, damit auch Container ohne Ladung (leer) im Ergebnis bleiben.
  • Bei leeren Containern ist sum(ci.weightKg) = null → coalesce(..., 0).
  • Bedingungen auf Aggregate (sum, count) gehören in having, nicht in where.
  • group by c (ganze Entity) funktioniert in Hibernate 6/7.
  • „mindestens“ = >= (Test limitIsInclusive).
Lösung ContainerRepository.findWithFreeCapacity
public List<Container> findWithFreeCapacity(long voyageId, double minFreeKg) {
    return getEntityManager().createQuery("""
                    select c from Container c
                    left join c.cargoItems ci
                    where c.voyage.id = :voyageId
                    group by c
                    having c.capacityKg - coalesce(sum(ci.weightKg), 0) >= :minFreeKg
                    order by c.containerNumber
                    """, Container.class)
            .setParameter("voyageId", voyageId)
            .setParameter("minFreeKg", minFreeKg)
            .getResultList();
}

Aufgabe 4 – Native SQL Query

  • em.createNativeQuery(sql) – echtes SQL: Tabellen- & Spaltennamen der DB (CONTAINERS, container_id, voyage_id…), siehe @Table/@Column/@JoinColumn.
  • Mehrere Spalten → Object[]; Zahlen immer über ((Number) x).longValue() casten (H2 liefert Long, andere DBs BigInteger/Integer).
  • count(...) liefert bei 0 Zeilen 0 (nicht null) → keine Sonderbehandlung nötig.
  • „Container zählen, nicht Ladungsposten“ → count(distinct c.id).
Lösung ContainerRepository.countByCategory
public CategoryCountDto countByCategory(long voyageId) {
    Object[] row = (Object[]) getEntityManager().createNativeQuery("""
                    select count(distinct case when f.climacteric then c.id end),
                           count(distinct case when not f.climacteric then c.id end)
                    from CONTAINERS c
                    join CARGO_ITEMS ci on ci.container_id = c.id
                    join FRUITS f on f.id = ci.fruit_id
                    where c.voyage_id = :voyageId
                    """)
            .setParameter("voyageId", voyageId)
            .getSingleResult();
    return new CategoryCountDto(((Number) row[0]).longValue(), ((Number) row[1]).longValue());
}

Aufgabe 5 – Service mit Regeln in fixer Reihenfolge

Muster: jede Regel = ein if + throw, genau in der Reihenfolge der Angabe. Erst ganz am Ende persist, dann wird bei Fehler nichts gespeichert.

  1. Existenz → findByIdOptional(..).orElseThrow(() -> new NotFoundException("...")) (404)
  2. Eingabe → BadRequestException (400)
  3. Fachregeln → eigene Exceptions (extends CargoRuleException → 409)
Überlappung von Bereichen: alle Bereiche überlappen ⇔ max(alle min) <= min(alle max).
Bidirektionale Beziehung: nach persist auch container.getCargoItems().add(item) – sonst stimmt getLoadedKg() in derselben Transaktion nicht.
Zahlen in Meldungen: %.1f nutzt Gebietsschema (DE → -1,0)! Double per %s ergibt immer -1.0.
Lösung CargoService.loadCargo
@Transactional
public CargoItem loadCargo(long containerId, CargoItemCreateDto dto) {
    // 1. existence -> 404
    Container container = containerRepository.findByIdOptional(containerId)
            .orElseThrow(() -> new NotFoundException("Container " + containerId + " not found"));
    Fruit fruit = fruitRepository.findByIdOptional(dto.fruitId())
            .orElseThrow(() -> new NotFoundException("Fruit " + dto.fruitId() + " not found"));

    // 2. weight > 0 -> 400
    if (dto.weightKg() == null || dto.weightKg() <= 0) {
        throw new BadRequestException("Weight must be greater than 0 kg");
    }

    // 3. climacteric separation -> 409 (empty container: getClimacteric() == null)
    Boolean containerClimacteric = container.getClimacteric();
    if (containerClimacteric != null && containerClimacteric != fruit.isClimacteric()) {
        throw new IncompatibleCargoException("%s is %s, but container %s holds %s fruits".formatted(
                fruit.getName(), category(fruit.isClimacteric()),
                container.getContainerNumber(), category(containerClimacteric)));
    }

    // 4. temperature ranges must overlap: highest minimum <= lowest maximum
    double highestMin = fruit.getMinTemperature();
    double lowestMax = fruit.getMaxTemperature();
    for (CargoItem item : container.getCargoItems()) {
        highestMin = Math.max(highestMin, item.getFruit().getMinTemperature());
        lowestMax = Math.min(lowestMax, item.getFruit().getMaxTemperature());
    }
    if (highestMin > lowestMax) {
        throw new TemperatureConflictException("%s (%s to %s °C) does not fit the temperature range of container %s"
                .formatted(fruit.getName(), fruit.getMinTemperature(), fruit.getMaxTemperature(),
                        container.getContainerNumber()));
    }

    // 5. capacity (exactly full is allowed) -> 409
    if (dto.weightKg() > container.getFreeKg()) {
        throw new CapacityExceededException("%.0f kg do not fit into container %s (free: %.0f kg)"
                .formatted(dto.weightKg(), container.getContainerNumber(), container.getFreeKg()));
    }

    CargoItem cargoItem = new CargoItem(dto.weightKg(), dto.originCountry(), container, fruit);
    cargoItemRepository.persist(cargoItem);
    container.getCargoItems().add(cargoItem); // keep the bidirectional relation in sync
    return cargoItem;
}

private static String category(boolean climacteric) {
    return climacteric ? "climacteric" : "non-climacteric";
}

public class ExceptionMappers {

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapCargoRule(CargoRuleException e) {
        return RestResponse.status(Response.Status.CONFLICT, new ErrorDto(e.getMessage()));
    }

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapNotFound(NotFoundException e) {
        return RestResponse.status(Response.Status.NOT_FOUND, new ErrorDto(e.getMessage()));
    }

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapBadRequest(BadRequestException e) {
        return RestResponse.status(Response.Status.BAD_REQUEST, new ErrorDto(e.getMessage()));
    }

    /** bean validation, e.g. "fruitId must not be null" */
    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapValidation(ConstraintViolationException e) {
        ConstraintViolation<?> violation = e.getConstraintViolations().iterator().next();
        String field = null;
        for (Path.Node node : violation.getPropertyPath()) {
            field = node.getName(); // last node = field name (path is "loadCargo.dto.fruitId")
        }
        return RestResponse.status(Response.Status.BAD_REQUEST, new ErrorDto(field + " " + violation.getMessage()));
    }
}

  readonly fruits = signal<FruitDto[]>([]);
  readonly containers = signal<ContainerDto[]>([]);

  readonly errorMessage = signal<string | null>(null);

    this.service.getVoyages().subscribe(v => this.voyages.set(v));
    this.service.getFruits().subscribe(f => this.fruits.set(f));

    const id = value ? Number(value) : null;
    this.selectedVoyageId.set(id);
    this.containerId.set(null);
    this.reload();
  }

  reload(): void {
    const id = this.selectedVoyageId();
    if (id === null) {
      this.containers.set([]);
      return;
    }
    this.service.getContainers(id).subscribe(c => this.containers.set(c));
  }

  toNumberOrNull(value: string): number | null {
    return value === '' ? null : Number(value);
  }

  load(): void {
    if (!this.formValid()) return;
    this.service.loadCargo(this.containerId()!, {
      fruitId: this.fruitId()!,
      weightKg: this.weightKg()!,
      originCountry: this.originCountry().trim()
    }).subscribe({
      next: () => {
        this.errorMessage.set(null);
        this.containerId.set(null);
        this.fruitId.set(null);
        this.weightKg.set(null);
        this.originCountry.set('');
        this.reload();
      },
      error: (err: HttpErrorResponse) => this.showError(err)
    });
  }

  removeItem(cargoItemId: number): void {
    this.service.deleteCargoItem(cargoItemId).subscribe({
      next: () => this.reload(),
      error: (err: HttpErrorResponse) => this.showError(err)
    });
  }

  private showError(err: HttpErrorResponse): void {
    this.errorMessage.set((err.error as ErrorDto | null)?.message ?? err.message);
  }
}

package at.htl.fruitshipping.control;

import at.htl.fruitshipping.control.exception.CapacityExceededException;
import at.htl.fruitshipping.control.exception.IncompatibleCargoException;
import at.htl.fruitshipping.control.exception.TemperatureConflictException;
import at.htl.fruitshipping.entity.CargoItem;
import at.htl.fruitshipping.entity.Container;
import at.htl.fruitshipping.entity.Fruit;
import at.htl.fruitshipping.entity.dto.CargoItemCreateDto;
import jakarta.enterprise.context.ApplicationScoped;
import jakarta.inject.Inject;
import jakarta.transaction.Transactional;
import jakarta.ws.rs.BadRequestException;
import jakarta.ws.rs.NotFoundException;

@ApplicationScoped
public class CargoService {

    @Inject
    ContainerRepository containerRepository;
    @Inject
    FruitRepository fruitRepository;
    @Inject
    CargoItemRepository cargoItemRepository;

    /**
     * Loads a cargo item into a container. Rules are checked in this order:
     * container and fruit exist, weight > 0, climacteric separation, temperature overlap, capacity.
     */
    @Transactional
    public CargoItem loadCargo(long containerId, CargoItemCreateDto dto) {
        // 1. existence -> 404
        Container container = containerRepository.findByIdOptional(containerId)
                .orElseThrow(() -> new NotFoundException("Container " + containerId + " not found"));
        Fruit fruit = fruitRepository.findByIdOptional(dto.fruitId())
                .orElseThrow(() -> new NotFoundException("Fruit " + dto.fruitId() + " not found"));

        // 2. weight > 0 -> 400
        if (dto.weightKg() == null || dto.weightKg() <= 0) {
            throw new BadRequestException("Weight must be greater than 0 kg");
        }

        // 3. climacteric separation -> 409 (empty container: getClimacteric() == null)
        Boolean containerClimacteric = container.getClimacteric();
        if (containerClimacteric != null && containerClimacteric != fruit.isClimacteric()) {
            throw new IncompatibleCargoException("%s is %s, but container %s holds %s fruits".formatted(
                    fruit.getName(), category(fruit.isClimacteric()),
                    container.getContainerNumber(), category(containerClimacteric)));
        }

        // 4. temperature ranges must overlap: highest minimum <= lowest maximum
        double highestMin = fruit.getMinTemperature();
        double lowestMax = fruit.getMaxTemperature();
        for (CargoItem item : container.getCargoItems()) {
            highestMin = Math.max(highestMin, item.getFruit().getMinTemperature());
            lowestMax = Math.min(lowestMax, item.getFruit().getMaxTemperature());
        }
        if (highestMin > lowestMax) {
            throw new TemperatureConflictException("%s (%s to %s °C) does not fit the temperature range of container %s"
                    .formatted(fruit.getName(), fruit.getMinTemperature(), fruit.getMaxTemperature(),
                            container.getContainerNumber()));
        }

        // 5. capacity (exactly full is allowed) -> 409
        if (dto.weightKg() > container.getFreeKg()) {
            throw new CapacityExceededException("%.0f kg do not fit into container %s (free: %.0f kg)"
                    .formatted(dto.weightKg(), container.getContainerNumber(), container.getFreeKg()));
        }

        CargoItem cargoItem = new CargoItem(dto.weightKg(), dto.originCountry(), container, fruit);
        cargoItemRepository.persist(cargoItem);
        container.getCargoItems().add(cargoItem); // keep the bidirectional relation in sync
        return cargoItem;
    }

    private static String category(boolean climacteric) {
        return climacteric ? "climacteric" : "non-climacteric";
    }
}

public class ExceptionMappers {

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapCargoRule(CargoRuleException e) {
        return RestResponse.status(Response.Status.CONFLICT, new ErrorDto(e.getMessage()));
    }

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapNotFound(NotFoundException e) {
        return RestResponse.status(Response.Status.NOT_FOUND, new ErrorDto(e.getMessage()));
    }

    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapBadRequest(BadRequestException e) {
        return RestResponse.status(Response.Status.BAD_REQUEST, new ErrorDto(e.getMessage()));
    }

    /** bean validation, e.g. "fruitId must not be null" */
    @ServerExceptionMapper
    public RestResponse<ErrorDto> mapValidation(ConstraintViolationException e) {
        ConstraintViolation<?> violation = e.getConstraintViolations().iterator().next();
        String field = null;
        for (Path.Node node : violation.getPropertyPath()) {
            field = node.getName(); // last node = field name (path is "loadCargo.dto.fruitId")
        }
        return RestResponse.status(Response.Status.BAD_REQUEST, new ErrorDto(field + " " + violation.getMessage()));
    }
}

import { Component, computed, inject, signal } from '@angular/core';
import { HttpErrorResponse } from '@angular/common/http';

import { ContainerDto, ErrorDto, FruitDto, VoyageDto } from '../model/dtos';

/** page: select a voyage, show its containers and load cargo */
@Component({
  selector: 'app-cargo',
  imports: [ContainerListComponent],
  templateUrl: './cargo.html',
  styleUrl: './cargo.css'
})
export class CargoComponent {
  private readonly service = inject(ShippingService);

  readonly voyages = signal<VoyageDto[]>([]);
  readonly fruits = signal<FruitDto[]>([]);
  readonly containers = signal<ContainerDto[]>([]);
  readonly selectedVoyageId = signal<number | null>(null);
  readonly errorMessage = signal<string | null>(null);

  // form state
  readonly containerId = signal<number | null>(null);
  readonly fruitId = signal<number | null>(null);
  readonly weightKg = signal<number | null>(null);
  readonly originCountry = signal('');

  readonly totalWeight = computed(() =>
    this.containers().reduce((sum, c) => sum + c.loadedKg, 0));

  readonly formValid = computed(() =>
    this.containerId() !== null &&
    this.fruitId() !== null &&
    (this.weightKg() ?? 0) > 0 &&
    this.originCountry().trim() !== '');

  constructor() {
    this.service.getVoyages().subscribe(v => this.voyages.set(v));
    this.service.getFruits().subscribe(f => this.fruits.set(f));
  }

  selectVoyage(value: string): void {
    const id = value ? Number(value) : null;
    this.selectedVoyageId.set(id);
    this.containerId.set(null);
    this.reload();
  }

  reload(): void {
    const id = this.selectedVoyageId();
    if (id === null) {
      this.containers.set([]);
      return;
    }
    this.service.getContainers(id).subscribe(c => this.containers.set(c));
  }

  toNumberOrNull(value: string): number | null {
    return value === '' ? null : Number(value);
  }

  load(): void {
    if (!this.formValid()) return;
    this.service.loadCargo(this.containerId()!, {
      fruitId: this.fruitId()!,
      weightKg: this.weightKg()!,
      originCountry: this.originCountry().trim()
    }).subscribe({
      next: () => {
        this.errorMessage.set(null);
        this.containerId.set(null);
        this.fruitId.set(null);
        this.weightKg.set(null);
        this.originCountry.set('');
        this.reload();
      },
      error: (err: HttpErrorResponse) => this.showError(err)
    });
  }

  removeItem(cargoItemId: number): void {
    this.service.deleteCargoItem(cargoItemId).subscribe({
      next: () => this.reload(),
      error: (err: HttpErrorResponse) => this.showError(err)
    });
  }

  private showError(err: HttpErrorResponse): void {
    this.errorMessage.set((err.error as ErrorDto | null)?.message ?? err.message);
  }
}
